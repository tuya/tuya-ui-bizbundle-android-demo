# 应用内多语言切换（In-App Language Switch）

本示例演示如何在涂鸦 BizBundle Demo（`tuya-ui-bizbundle-android-demo`）中实现**应用内多语言切换**：不依赖系统语言设置，由 App 自行切换语言，并在重启后依然生效。

> 示例代码位于 `app` 模块（Java，包名 `com.tuya.smart.bizubundle.demo`）。

---

## 一、方案：AppCompatDelegate.setApplicationLocales（官方 API）

直接复用 AndroidX 官方的 per-app 语言 API：

```java
AppCompatDelegate.setApplicationLocales(LocaleListCompat.forLanguageTags("zh"));
```

**为什么用它**：它会把语言应用到**所有 Activity**——包括 SDK 业务包（BizBundle）里库模块的页面。原理是 `AppCompatDelegate` 会在全局拦截每个 Activity 的 `attachBaseContext`；在 Android 13（API 33+）上还走系统级 per-app 语言机制，连普通 `Activity`（非 AppCompat）也能覆盖。

> 本项目 `app/build.gradle` 声明的是 `androidx.appcompat:appcompat:1.2.0`，但 SDK 的 `thingsmart-BizBundlesBom` 把它 **resolve 到了 1.6.1**（可用 `./gradlew :app:dependencyInsight --dependency androidx.appcompat:appcompat --configuration debugRuntimeClasspath` 验证），所以该 API 可直接使用，无需改任何依赖。

## 二、实现说明（app 模块，Java）

### 1. `LocaleHelper` —— 核心工具类

路径：[app/src/main/java/com/tuya/smart/bizubundle/demo/language/LocaleHelper.java](../app/src/main/java/com/tuya/smart/bizubundle/demo/language/LocaleHelper.java)

```java
public static void switchLanguage(Context context, String language) {
    LocaleListCompat locales = LANG_SYSTEM.equals(language)
            ? LocaleListCompat.getEmptyLocaleList()            // 跟随系统
            : LocaleListCompat.forLanguageTags(language);
    AppCompatDelegate.setApplicationLocales(locales);
}

public static String getLanguage(Context context) {
    LocaleListCompat locales = AppCompatDelegate.getApplicationLocales();
    if (locales.isEmpty()) return LANG_SYSTEM;                 // 跟随系统
    Locale l = locales.get(0);
    // ...映射回 LANG_ENGLISH / LANG_CHINESE / 实际语言
}
```

支持的语言常量：

```java
public static final String LANG_SYSTEM = "";   // 空串表示跟随系统
public static final String LANG_ENGLISH = "en";
public static final String LANG_CHINESE = "zh";
```

特性：
- **全局生效**：覆盖所有 Activity（含 SDK BizBundle 页面）。
- **自动持久化**：appcompat / 系统自动保存选择，冷启动后仍生效（`getApplicationLocales()` 能读回）。
- **自动刷新**：调用后当前 Activity 会被 recreate，无需手动重启 App。

### 2. `MainActivity` —— 切换入口

路径：[app/src/main/java/com/tuya/smart/bizubundle/demo/MainActivity.java](../app/src/main/java/com/tuya/smart/bizubundle/demo/MainActivity.java)

主页在「主题色切换」下方新增「Language / 语言」入口，点击弹单选列表，选择后调用 `switchLanguage` 即可（无需 restart）：

```java
private void showLanguageDialog() {
    final String[][] options = {
            {LocaleHelper.LANG_ENGLISH, getString(R.string.language_en)},
            {LocaleHelper.LANG_CHINESE, getString(R.string.language_zh)},
            {LocaleHelper.LANG_SYSTEM, getString(R.string.language_system)}
    };
    // ... 构造 labels、计算 checkedItem
    new AlertDialog.Builder(this)
            .setTitle(getString(R.string.language_dialog_title))
            .setSingleChoiceItems(labels, checkedItem, (dialog, which) -> {
                dialog.dismiss();
                // 全局生效：当前页面自动 recreate，业务包页面随后也用新语言
                LocaleHelper.switchLanguage(this, options[which][0]);
            })
            .setNegativeButton(android.R.string.cancel, null)
            .show();
}
```

### 3. 字符串资源

为避免改动 Demo 里超大的 `strings.xml`，语言相关文案放在**独立文件**里，Android 会自动合并：

- [app/src/main/res/values/strings_language.xml](../app/src/main/res/values/strings_language.xml)（英文，默认）
- [app/src/main/res/values-zh/strings_language.xml](../app/src/main/res/values-zh/strings_language.xml)（中文）

```xml
<string name="language_setting">Language</string>           <!-- 语言 -->
<string name="language_dialog_title">Select Language</string><!-- 选择语言 -->
<string name="language_en">English</string>
<string name="language_zh">简体中文</string>
<string name="language_system">Follow System</string>       <!-- 跟随系统 -->
```

布局：[app/src/main/res/layout/activity_main.xml](../app/src/main/res/layout/activity_main.xml) 中，在 `theme_switch`（主题色切换）下方新增 `language` 入口。

## 三、如何使用

1. 运行 `tuya-ui-bizbundle-android-demo`，登录后进入主页（`MainActivity`）。
2. 点击「**Language / 语言**」入口（`R.id.language`，在"主题色切换"下面）。
3. 在弹窗中选择 **English / 简体中文 / 跟随系统**：
   - 当前页面会自动刷新为新语言；
   - 进入各业务包（设备控制、场景、设备详情、消息中心等）也都是新语言。
4. 选择由 appcompat/系统自动持久化，**之后每次冷启动**都按所选语言加载。

### 在你自己的代码里调用

```java
// 切换为中文（全局生效，当前页面自动 recreate）
LocaleHelper.switchLanguage(context, LocaleHelper.LANG_CHINESE);

// 切换为英文
LocaleHelper.switchLanguage(context, LocaleHelper.LANG_ENGLISH);

// 跟随系统
LocaleHelper.switchLanguage(context, LocaleHelper.LANG_SYSTEM);

// 读取当前选择（"" 表示跟随系统）
String lang = LocaleHelper.getLanguage(context);
```

> 新增语言选项需同时：① 在 `LocaleHelper` 增加 `LANG_XXX` 常量并在弹窗 `options` 加入；② 在 `values-<语言>/` 目录补充字符串资源。

---

## 四、新增语言步骤（示例：日语）

1. 在 `LocaleHelper` 增加 `public static final String LANG_JAPANESE = "ja";`
2. 新建资源目录 `app/src/main/res/values-ja/strings_language.xml`，翻译所需文案。
3. 在弹窗 `options` 数组中追加 `{LocaleHelper.LANG_JAPANESE, getString(R.string.language_ja)}`。
4. （`getLanguage` 的回读映射按需补一个 `LANG_JAPANESE` 分支。）

## 五、说明

- **本实现只新增了多语言代码，未改动任何 SDK 集成配置**（`build.gradle` 的依赖、`gradle.properties`、Manifest 的 AppKey/AppSecret、applicationId、security-algorithm、签名等均未触碰；appcompat 1.6.1 是 SDK BOM 自动拉高的，不是我们改的）。
- **API 33+ vs <33**：33+ 走系统 per-app 语言（覆盖所有 Activity，含普通 `Activity`）；<33 走 appcompat 拦截（覆盖 `AppCompatActivity`）。本 Demo 的 `minSdk=24`，绝大多数 BizBundle 页面是 `AppCompatActivity`，均已覆盖。
