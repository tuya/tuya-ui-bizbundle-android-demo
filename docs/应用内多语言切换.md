# 应用内多语言切换（In-App Language Switch）

本示例演示如何在涂鸦 BizBundle Demo（`tuya-ui-bizbundle-android-demo`）中实现**应用内多语言切换**：不依赖系统语言设置，由 App 自行切换语言、持久化选择，并在重启后依然生效。

> 示例代码位于 `app` 模块（Java，包名 `com.tuya.smart.bizubundle.demo`）。

**核心机制**：通过更新 Application 级别 `Resources` 的 `Configuration.locale`，再用 `updateConfiguration(...)` 让资源按新语言刷新。
**持久化**：用户选择存入 `SharedPreferences`，App 重启后仍生效。
**切换后重启**：与涂鸦 SDK 官方一致，切完语言后重启 App（拉起 launcher + 杀进程），让新语言全量生效（含 BizBundle 内部 UI）。

---

## 一、实现说明（app 模块，Java）

### 1. `LocaleHelper` —— 核心工具类

路径：[app/src/main/java/com/tuya/smart/bizubundle/demo/language/LocaleHelper.java](../app/src/main/java/com/tuya/smart/bizubundle/demo/language/LocaleHelper.java)

提供四个对外能力：

| 方法 | 作用 | 对应 SDK |
| --- | --- | --- |
| `switchLanguage(context, language)` | 持久化语言 + 立即更新 App 级资源 | `ThingLanguageUtils.switchLanguage` |
| `restartApp(context)` | 切换后重启 App（拉起 launcher + 杀进程），让新语言全量生效 | `ApplicationUtil.relaunchApp(true)` |
| `wrap(context)` | 用持久化的语言包装 Context，供 `attachBaseContext` 调用 | —— |
| `getLanguage(context)` | 读取当前持久化的语言 | —— |

关键代码：

```java
@SuppressWarnings("DEPRECATION")
public static void switchLanguage(Context context, String language) {
    saveLanguage(context, language);                              // ① 持久化

    Resources res = context.getApplicationContext().getResources();
    Configuration config = new Configuration(res.getConfiguration());
    applyLocale(config, resolveLocale(language));                // ② 设置 locale
    res.updateConfiguration(config, res.getDisplayMetrics());    // ③ 刷新资源（同 SDK）
}
```

重启 App（镜像 SDK `ApplicationUtil.relaunchApp(true)`）：

```java
public static void restartApp(Context context) {
    Intent intent = context.getPackageManager()
            .getLaunchIntentForPackage(context.getPackageName());
    if (intent == null) return;
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK
            | Intent.FLAG_ACTIVITY_CLEAR_TOP
            | Intent.FLAG_ACTIVITY_CLEAR_TASK);
    context.startActivity(intent);
    android.os.Process.killProcess(android.os.Process.myPid());
    System.exit(0);
}
```

支持的语言常量（可按需扩展）：

```java
public static final String LANG_SYSTEM = "";   // 空串表示跟随系统
public static final String LANG_ENGLISH = "en";
public static final String LANG_CHINESE = "zh";
```

> `LANG_SYSTEM`（跟随系统）会读取 `Resources.getSystem()` 的真实系统语言，不受 App 自身的覆盖影响。

### 2. `BaseActivity` —— 让页面生效

路径：[app/src/main/java/com/tuya/smart/bizubundle/demo/language/BaseActivity.java](../app/src/main/java/com/tuya/smart/bizubundle/demo/language/BaseActivity.java)

```java
public abstract class BaseActivity extends AppCompatActivity {
    @Override
    protected void attachBaseContext(Context newBase) {
        super.attachBaseContext(LocaleHelper.wrap(newBase));
    }
}
```

凡是需要支持语言切换的页面，把父类从 `AppCompatActivity` 改成 `BaseActivity` 即可。本 Demo 已把 `MainActivity` 改为继承它；`ThemeActivity` 未改（仍由 `TuyaSmartApp` 的应用级注入拿到语言，如需它也走 BaseActivity 可自行调整）。

### 3. `TuyaSmartApp` —— 应用级注入

路径：[app/src/main/java/com/tuya/smart/bizubundle/demo/TuyaSmartApp.java](../app/src/main/java/com/tuya/smart/bizubundle/demo/TuyaSmartApp.java)

```java
@Override
protected void attachBaseContext(Context base) {
    super.attachBaseContext(LocaleHelper.wrap(base));  // 注入持久化语言
    MultiDex.install(this);                            // 保留原有 MultiDex 逻辑
}
```

保证 App 重启（进程重建）后，资源也按持久化的语言加载；同时让库内页面也能跟随。

### 4. 调用示例 —— 切换入口

路径：[app/src/main/java/com/tuya/smart/bizubundle/demo/MainActivity.java](../app/src/main/java/com/tuya/smart/bizubundle/demo/MainActivity.java)

主页 `MainActivity` 在「主题色切换」下方新增「Language / 语言」入口，点击弹出单选列表，选择后切换并**重启 App**：

```java
private void showLanguageDialog() {
    // [language code, display label]
    final String[][] options = {
            {LocaleHelper.LANG_ENGLISH, getString(R.string.language_en)},
            {LocaleHelper.LANG_CHINESE, getString(R.string.language_zh)},
            {LocaleHelper.LANG_SYSTEM, getString(R.string.language_system)}
    };
    String[] labels = new String[options.length];
    for (int i = 0; i < options.length; i++) labels[i] = options[i][1];

    int checkedItem = -1;
    String current = LocaleHelper.getLanguage(this);
    for (int i = 0; i < options.length; i++) {
        if (options[i][0].equals(current)) { checkedItem = i; break; }
    }

    new AlertDialog.Builder(this)
            .setTitle(getString(R.string.language_dialog_title))
            .setSingleChoiceItems(labels, checkedItem, (dialog, which) -> {
                dialog.dismiss();
                LocaleHelper.switchLanguage(this, options[which][0]); // 持久化 + 刷新资源
                LocaleHelper.restartApp(this);                        // 重启 App，新语言全量生效
            })
            .setNegativeButton(android.R.string.cancel, null)
            .show();
}
```

### 5. 字符串资源

为避免改动 Demo 里超大的 `strings.xml`，语言相关文案放在**独立文件**里，Android 会自动合并：

- [app/src/main/res/values/strings_language.xml](../app/src/main/res/values/strings_language.xml)（英文，默认）
- [app/src/main/res/values-zh/strings_language.xml](../app/src/main/res/values-zh/strings_language.xml)（中文）

```xml
<string name="language_setting">Language</string>           <!-- 语言 -->
<string name="language_dialog_title">Select Language</string><!-- 选择语言 -->
<string name="language_en">English</string>
<string name="language_zh">简体中文</string>
<string name="language_system">Follow System</string>       <!-- 跟随系统 -->
```

布局：[app/src/main/res/layout/activity_main.xml](../app/src/main/res/layout/activity_main.xml) 中，在 `theme_switch`（主题色切换）下方新增 `language` 入口（`TextView`，与其它业务入口同款）。

## 二、如何使用

1. 运行 `tuya-ui-bizbundle-android-demo`，登录后进入主页（`MainActivity`）。
2. 点击列表中的「**Language / 语言**」入口（`R.id.language`，在"主题色切换"下面）。
3. 在弹窗中选择 **English / 简体中文 / 跟随系统**，App 会**自动重启**（回到启动页），并以新语言全量加载（含 BizBundle 内部 UI）。
4. 由于选择已持久化，**之后每次冷启动**都按所选语言加载（`SharedPreferences` 持久化 + `attachBaseContext` 注入）。

### 在你自己的代码里调用

```java
// 切换为中文（切完重启 App，新语言全量生效）
LocaleHelper.switchLanguage(context, LocaleHelper.LANG_CHINESE);
LocaleHelper.restartApp(context);

// 切换为英文
LocaleHelper.switchLanguage(context, LocaleHelper.LANG_ENGLISH);
LocaleHelper.restartApp(context);

// 跟随系统
LocaleHelper.switchLanguage(context, LocaleHelper.LANG_SYSTEM);
LocaleHelper.restartApp(context);

// 读取当前选择（"" 表示跟随系统）
String lang = LocaleHelper.getLanguage(context);
```

> 新增语言选项需同时：① 在 `LocaleHelper` 增加常量并在 `resolveLocale(...)` 映射到对应 `Locale`；② 在 `values-<语言>/` 目录补充字符串资源。

## 三、新增语言步骤（示例：日语）

1. 在 `LocaleHelper` 增加：
   ```java
   public static final String LANG_JAPANESE = "ja";
   // resolveLocale(...) 中：
   if (LANG_JAPANESE.equals(language)) return Locale.JAPANESE;
   ```
2. 新建资源目录 `app/src/main/res/values-ja/strings_language.xml`，翻译所需文案（或新建 `strings.xml`）。
3. 在弹窗 `options` 数组中追加 `{LocaleHelper.LANG_JAPANESE, getString(R.string.language_ja)}`。
4. 确保所在 Activity 继承自 `BaseActivity`，切换后调用 `LocaleHelper.restartApp(context)` 重启 App。

## 四、说明

- **本实现只新增/接入了多语言代码，未改动任何 SDK 集成配置**（`build.gradle`、`gradle.properties`、`local.properties`、Manifest 的 AppKey/AppSecret、applicationId、security-algorithm、签名等均未触碰）。
- **appcompat 版本**：Demo 使用 `androidx.appcompat:appcompat:1.2.0`，该版本会包裹 Activity 的 base context，因此必须通过 `BaseActivity.attachBaseContext` 注入语言，否则切换不会在页面上生效。本实现已处理。
- **切换后重启**：因为会杀进程回到启动页，切语言后需要重新走一遍启动/登录流程——这是涂鸦 SDK 的固有行为（`DebugPresenter` 切语言后即调 `restartApplication`）。
